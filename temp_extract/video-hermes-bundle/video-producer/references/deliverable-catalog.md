# Deliverable Catalog

## Purpose

Use this catalog to verify what each downstream skill should return before the workflow moves on.

## Deliverables by Skill

### `video-concept-architect`

Required:
- recommended format
- chosen angle
- asset strategy
- production concept

Good extras:
- 1 to 2 fallback concepts

### `video-style-translator`

Required:
- style summary
- adaptation rules
- non-copying boundaries

Good extras:
- workflow-specific notes for the next owner

### `video-clips-editor`

Required:
- ranked clip shortlist
- hook line per clip
- timestamps or approximate ranges
- platform packaging notes

### `video-speaker-editor`

Required:
- editing posture
- segment map
- subtitle plan
- emphasis/framing notes

### `video-demo-director`

Required:
- chosen demo mode
- beat map
- proof moments
- capture or composition notes

### `video-localization-producer`

Required:
- localization mode per language
- terminology notes
- timing risk notes
- per-language delivery plan

### `video-motion-designer`

Required:
- selected visual mode
- visual system summary
- scene plan
- motion constraints

### `video-story-editor`

Required:
- story shape
- emotional arc
- beat map
- visual/audio plan

### `video-hybrid-director`

Required:
- anchor-medium decision
- support-layer map
- integration plan

## Acceptance Rule

Do not mark a lane complete just because it returned something well-written. Mark it complete only when the returned deliverables are specific enough for the next stage to act on.
