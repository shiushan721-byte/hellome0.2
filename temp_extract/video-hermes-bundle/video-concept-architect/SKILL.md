# Video Concept Architect

Take an idea that is still soft and make it solid enough for production.

Use this skill when the user does not yet know exactly what kind of video they should make, what structure fits best, or what assets the idea requires.

## Inputs

Expect:
- user goal
- audience
- available inputs
- missing inputs
- style signal if any
- success definition

Useful inputs include:
- rough notes
- reference videos
- brand or campaign context
- product or service description
- launch or distribution context

## Workflow

1. Clarify the core promise.
2. Choose the best video format.
3. Define the winning angle.
4. Choose the asset strategy.
5. Return a production-ready concept package.

## Core Promise

Identify:
- what the viewer should understand, feel, or do
- what makes this video worth watching
- what makes it different from generic category content

If the idea has no clear promise, fix that before proposing formats.

## Format Selection

Choose the strongest format for the goal:
- `short-social`
- `product-demo`
- `talking-head`
- `cinematic-montage`
- `explainer-animation`
- `hybrid-showcase`
- `localized-adaptation`

Use [references/format-selection.md](./references/format-selection.md) when the choice is not obvious.

## Angle Definition

A good concept is not just a topic. Define:
- the core angle
- the opening promise
- the audience fit
- the reason this angle beats the alternatives

When multiple good angles exist, return 2 to 3 options max and recommend one.

## Asset Strategy

Choose the production reality:
- source-led
- speaker-led
- screen-led
- design-led
- generated-led
- hybrid

Make clear what already exists, what must be created, and what can be approximated with defaults.

Use [references/asset-strategy.md](./references/asset-strategy.md) when tradeoffs need explanation.

## Failure and Escalation

Escalate when:
- the objective itself is unclear
- the user is mixing too many goals into one video
- the desired output conflicts sharply with available assets
- the brief should go back up for more audience or business-context clarification

## Output

Return:
- recommended format
- chosen angle
- audience-fit rationale
- asset strategy
- one-paragraph production concept
- optional fallback concepts if helpful
