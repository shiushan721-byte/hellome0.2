# Platform Packaging

## Purpose

Adjust the same source idea to different platforms without changing the core message.

## Default Patterns

### Douyin / Reels / Shorts

- get to the hook immediately
- keep captions highly readable
- prefer one dominant idea
- use punchy visual emphasis

### Xiaohongshu

- lean slightly more explanatory
- keep the hook but add clarity
- allow a touch more context if the value is educational

### LinkedIn

- prefer proof, clarity, and credibility
- reduce sensational framing
- let the clip feel more composed than hyperactive

## Packaging Variables

Tune:
- opening line
- subtitle density
- whether to show title cards
- whether to include speaker labels
- whether the ending should tease more or land conclusively
