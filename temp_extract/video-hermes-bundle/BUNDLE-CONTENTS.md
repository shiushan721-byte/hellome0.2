# Video Hermes Bundle

This folder contains the reusable video skill system prepared for Hermes-style integration.

## Included Packages

- `video-producer`
- `video-concept-architect`
- `video-style-translator`
- `video-clips-editor`
- `video-speaker-editor`
- `video-demo-director`
- `video-localization-producer`
- `video-motion-designer`
- `video-story-editor`
- `video-system-examples`
- `video-hermes-integration`

## Start Here

1. Read `video-hermes-integration/references/hermes-final-system-prompt.md`
2. Load `video-producer` as the front-door owner
3. Load the specialist backend skills
4. Use `video-system-examples` for validation, scoring, and pressure testing
